# HiOtaku Flutter App

🎬 Anime streaming app with video player and API integration

## Features
- 🎥 Video streaming with multiple sources
- 🔍 Anime search and discovery
- 📱 Cross-platform (Android/iOS)
- 🎯 API integration for content

## Getting Started

### Prerequisites
- Flutter SDK 3.16.0+
- Dart 3.0+
- Android Studio / VS Code

### Installation
```bash
git clone https://github.com/hiotakuofficial-cloud/Test.git
cd Test
flutter pub get
flutter run
```

### Build
```bash
# Android APK
flutter build apk --release

# iOS
flutter build ios --release
```

## API Integration
- Hiotaku API for anime content
- Video source extraction
- Multiple server support
